# Tavrix DMMS

Browser-based restaurant ordering and management for customers, counter staff,
kitchen staff, and owners.

## Run locally

```bash
npm run dev
```

Configure the required environment variables before starting the app; see
[DEPLOYMENT.md](./DEPLOYMENT.md).
